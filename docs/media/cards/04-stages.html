Probation + UndertakerFile No. 04 · The lifecycle

Nine stages. One lifecycle.

GitLab CI → Cloud Run
  1. 01
    Plan
    Nightly census files a grave issue for code production proves dead.
  2. 02
    Create
    Undertaker flow digs it: a deletion-only MR plus a coroner’s report.
  3. 03
    Verify
    verify:check (lint, types, tests) and a replay of real traffic.
  4. 04
    Package
    Cloud Build builds the image; its size feeds the SCI note.
  5. 05
    Secure
    SAST, secret and dependency scanning, plus an npm audit gate.
  6. 06
    Release
    Canary child pipeline: staging → canary → soak → promote.
  7. 07
    Configure
    Cloud Run revision tags, traffic split and feature flags.
  8. 08
    Monitor
    Soak synthetics and census request logs watch production.
  9. 09
    Govern
    policy.yml, CODEOWNERS and the append-only ledger decide autonomy.
Every stage is a job in .gitlab-ci.ymlNothing ships without passing all nine.
